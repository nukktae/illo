# 벤치마크 플랫폼 (국내 + 해외)

작성 2026-10-27 · 기준: 일로의 세 기능과 얼마나 닮았는가

| 일로 기능 | 설명 |
|---|---|
| 1. 진단 | 내 이력서와 실제 공고를 비교해 부족 역량 찾기 |
| 2. 준비 순서 | 부족 역량에 우선순위 매기기 |
| 3. 과정 연결 | 부족 역량을 채울 SeSAC 과정 추천 |
| 4. 기관 대시보드 | 공고 기반 역량 수요를 서울시, SeSAC에 피드백 |

|---|---|---|---|---|---|---|---|
| SkillsFuture Jobs-Skills Portal | 싱가포르 | 정부 (SSG) | 있음 | 일부 | 있음 | 있음 | 전체 구조가 가장 비슷한 공공 모델 |
| Lightcast SkillsMatch, Career Coach, Skillabi | 미국 | 민간 (대학 납품) | 있음 | 일부 | 있음 (자기 학교 과정) | 있음 (Skillabi) | 교육기관 단위로 납품하는 구조 |
| 고용24 AI 서비스 | 한국 | 정부 (고용노동부) | 있음 (취업확률) | 없음 | 있음 (훈련 추천) | 확인 못 함 | 국내 공공 경쟁자 |
| Jobscan, Teal | 미국 | 민간 | 있음 (공고 1건 기준) | 없음 | 없음 | 없음 | 매칭률 점수와 부족 키워드 표시 방식 |
| Coursera (Coach, 역할별 경로) | 글로벌 | 민간 | 일부 | 없음 | 있음 (자사 강의) | 대학용 분석 | 직무 기준 학습 경로 |
| 잡코리아, 사람인 | 한국 | 민간 | 확인 못 함 | 없음 | 일부 (자격증 안내) | 없음 | 이력서 기반 공고 추천 |
| 코멘토 직무부트캠프 | 한국 | 민간 | 없음 | 없음 | 자사 과정 | 없음 | 직무 이해 중심 단기 과정 |

"확인 못 함"은 이번 검색에서 근거를 찾지 못했다는 뜻이지, 기능이 없다는 뜻은 아닙니다.

## 2. 플랫폼별 정리

### SkillsFuture Jobs-Skills Portal (싱가포르) · 가장 중요한 벤치마크
| 항목 | 내용 |
|---|---|
| 출시 | 2025년 1월, 개인 기업 교육기관 통합 포털 |
| Transition Pathways | 현재 직무와 목표 직무의 역량을 비교하고, 겹치는 역량과 필요한 과정을 보여줌. 이동 시 예상 임금 상승도 표시 |
| 기관용 | 2025년 10월 Job Requirement (Skills) Index 공개. 849개 직무의 역량 수요 변화 추적 |
| 개인용 | Jobs-Skills Profile Dashboard. 직무별 기업이 찾는 상위 역량 |
| 일로에 주는 것 | 개인 진단과 기관 대시보드를 한 데이터로 묶는 구조가 이미 정부 정책으로 운영 중이라는 근거. 발표에서 "서울판 SkillsFuture"로 설명 가능 |
| 차이 | 싱가포르는 국가 역량 체계(Skills Framework) 위에서 작동. 일로는 실제 공고에서 바로 역량을 뽑음 |

### Lightcast (미국)
| 항목 | 내용 |
|---|---|
| SkillsMatch | 학습자의 현재 역량과 원하는 역량을 넣으면 그 학교의 과정을 추천. 학교 브랜드로 납품 (예: Boston University) |
| Career Coach | 관심사와 역량, 지역 채용 수요로 진로와 학과를 추천 |
| Skillabi | 학교 커리큘럼을 공고 데이터와 비교해 빠진 역량을 찾음 |
| 공고 분석 방식 | 기본 역량(자주 나오는 것)과 신규 역량(최근 크게 증가한 것)으로 나눔 |
| 일로에 주는 것 | 일로의 "SeSAC 과정 개편 제안" 기능과 Skillabi가 같은 개념. 역량을 "기본"과 "급상승"으로 나누는 방식은 그대로 차용할 만함 |
| 차이 | 대학이 돈을 내는 B2B. 일로는 서울시와 SeSAC 한 기관에 특화 |

### 고용24 AI 고용서비스 (한국) · 반드시 차별점 정리 필요
| 항목 | 내용 |
|---|---|
| 2025년 9월 | 지능형 직업심리검사(적합 직업군 5개 추천), 데이터 기반 취업확률, AI 직업훈련 추천 등 공개 |
| 2026년 6월 발표 | 취업확률 기반 구직컨설팅: 희망 직종 취업 가능성을 분석하고 훈련, 자격증, 이력서 보완 사항 제시. 8월 정식 운영 예정이라고 발표 |
| 연계 | AI 훈련 추천과 AI 일자리 추천을 연결 |
| 일로와 겹치는 점 | 진단과 훈련 추천을 정부가 이미 하고 있음. 심사위원이 "고용24랑 뭐가 달라요?"라고 물을 가능성 높음 |
| 일로의 차별점 후보 | 실제 공고 문장을 근거로 보여줌, SeSAC 과정 상세 차시까지 연결, 서울시와 SeSAC로 수요 피드백 |
| 확인할 것 | 8월 정식 운영 여부, 실제 화면. 팀원이 고용24에서 직접 써보고 캡처 필요 |

### Jobscan, Teal (미국)
| 항목 | 내용 |
|---|---|
| 방식 | 이력서와 공고 1건을 비교해 매칭률(%)과 있는 키워드, 없는 키워드를 보여줌 |
| 기준 | Jobscan은 75% 이상 권장, Teal은 80% 이상을 강한 매칭으로 봄 |
| 주의점 | 점수를 100%로 맞추려다 이력서가 부자연스러워진다는 비판 |
| 일로에 주는 것 | "있음 / 없음 / 추천" 3단 키워드 표시는 결과 화면에 바로 쓸 수 있음 |
| 차이 | 공고 1건 단위. 일로는 공고 수천 건을 모아 시장 전체 기준으로 진단 |

### Coursera (글로벌)
| 항목 | 내용 |
|---|---|
| 2025년 4월 | 수요 많은 60개 직무별 맞춤 추천, AI 가이드 Coursera Coach |
| 인용할 숫자 | 학습자의 약 3분의 2가 목표에 필요한 역량을 모른다고 Coursera가 발표 |
| 대학용 | 학생 역량과 목표 직무 사이 간격을 계산하는 Skills Report |
| 일로에 주는 것 | "무슨 역량이 필요한지 모른다"는 문제를 글로벌 기업도 핵심 문제로 본다는 근거 |

### 잡코리아, 사람인 (한국)
| 항목 | 내용 |
|---|---|
| 잡코리아 | 이력서와 희망 조건으로 공고 추천, 커리어첵첵(스펙 등록 시 AI 가이드, 필요 자격증, 면접 팁), AI 매칭 원픽 |
| 사람인 | 이력서와 관심 기업으로 추천 기업, AI 기업 매칭 |
| 확인 못 함 | 공고 적합도 점수나 부족 역량 진단 기능 |
| 일로와의 차이 | 채용 플랫폼은 "어디에 지원할까"가 목적. 일로는 "지원 전에 무엇을 채울까"가 목적 |

### 코멘토 직무부트캠프 (한국)
| 항목 | 내용 |
|---|---|
| 방식 | 5주, 과제가 70% 이상, 현직자 피드백 |
| 익스턴십 | 무료, 실무 과제 평가로 입사 제안 |
| 일로에 주는 것 | 직무 이해가 먼저 필요한 비전공자에게 "짧은 맛보기"가 통한다는 사례. 준비 순서의 1단계로 연결할 수 있는 외부 자원 |

## 3. 일로가 가져갈 것

| 아이디어 | 출처 | 적용 위치 |
|---|---|---|
| 현재 직무와 목표 직무의 겹치는 역량을 먼저 보여줘 자신감 주기 | SkillsFuture | 진단 결과 첫 화면 |
| 역량을 "기본"과 "급상승"으로 구분 | Lightcast | 역량 표, 기관 대시보드 |
| 있음 / 없음 / 추천 3단 키워드 | Jobscan, Teal | 진단 결과 |
| 매칭률은 보여주되 100%를 목표로 만들지 않기 | Jobscan 비판 | 점수 문구 |
| 커리큘럼과 공고를 비교해 빠진 역량 제안 | Lightcast Skillabi | SeSAC 과정 개편 제안 |
| 직무별 상위 역량 리포트를 기관에 정기 발행 | SkillsFuture JRSI, LinkedIn | 기관 대시보드 |

## 4. 발표에서 쓸 차별점 문장 (초안)

| 비교 대상 | 일로의 답 |
|---|---|
| 고용24 | 고용24는 직종 단위로 취업확률을 봅니다. 일로는 실제 공고 문장을 근거로 무엇이 부족한지 보여주고, SeSAC 과정의 어느 차시에서 채우는지까지 연결합니다 |
| 채용 플랫폼 | 채용 플랫폼은 지원할 곳을 추천합니다. 일로는 지원 전에 채울 것을 알려줍니다 |
| Jobscan류 | 공고 1건이 아니라 서울 공고 수천 건을 기준으로 진단합니다 |
| SkillsFuture | 싱가포르가 국가 단위로 하는 개인 진단과 기관 피드백을, 서울과 SeSAC 단위로 빠르게 구현합니다 |
