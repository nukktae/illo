## 2. 최신 정책 방향: 청년취업사관학교 2.0 (2025-11-11 발표)

공식 이름 "1089(십중팔구) 프로젝트". 일로가 맞춰야 할 기준입니다.

| 목표 | 수치 |
|---|---|
| 취업 목표 | 교육생의 80~90%를 양질의 일자리로 |
| 교육 인원 | 2025년 3,300명, 2030년 연 1만 명 |
| 빅테크 전담 캠퍼스 | 2026년 4월 8곳으로 확대 (MS, Intel, Salesforce, Oracle, KT, NVIDIA 등) |
| 인턴십 | 2026년 300개 발굴, 2030년 연 1,000명. 시정연계 인턴 2026년 100명 |
| 고급 인재 트랙 | 매년 수료생 20명 선발 |
| 시장 비전 | "배움이 곧 취업과 창업으로 이어지는 AI 인재 양성 종합 플랫폼" |

2.0에서 바뀐 운영 규칙 중 일로와 관련 있는 것
| 변경 | 내용 | 일로와의 관계 |
|---|---|---|
| 중도 탈락 기준 상향 | 70점에서 80점 | 입과 후 못 따라가면 탈락 위험이 커짐. 입과 전 준비가 더 중요해짐 |
| 무단 포기자 재참여 제한 | 신설 | 잘못 고른 과정의 대가가 커짐 |
| 재교육 허용 | 생애 2회 제한 폐지, 1년 후 재참여 | 재도전자에게 "지난번에 무엇이 부족했나" 진단 수요 |
| 학과 운영위원회 신설 | 과정 신설과 폐지, 강사 기준 결정 | 일로의 기관 대시보드가 근거 자료를 줄 수 있는 곳 |

## 3. 정책의 빈 곳 (사각지대)

### 근거 1. 서울시의회 행정사무감사 지적
2025년 11월 5일 경제실 행정사무감사, 이민옥 의원 (서울신문 2025-11-28 보도)

| 지적 | 내용 |
|---|---|
| 취업률 산정 | 2024년 취업률 76.1% (1,436명)는 단기 고용보험 가입만 반영 |
| 유지율 미관리 | 6개월, 1년 고용 유지율을 핵심 성과지표로 관리하지 않음 |
| 사후관리 부족 | "교육, 수료, 단기 취업, 이탈"이 반복될 우려 |
| 현장 수요와 괴리 | 교육과 현장 요구 사이 간격 |
| 단기 과정 한계 | 3~6개월 과정으로 고급 SW, AI 인재 양성에 한계 |
| 제안 | "교육 후 6개월 이상 동일 기업 근속자 비율" 같은 질적 지표 도입 |

서울시의 공식 답변은 기사에 없습니다.

### 근거 2. 정책 문서에 없는 단계
2.0 발표문, 정책 아카이브, 빅테크 캠퍼스 발표를 모두 확인했지만 아래 내용은 없습니다.

| 없는 것 | 확인 결과 |
|---|---|
| 지원 전 수준 진단, 과정 추천 | 없음. 선발용 레벨테스트만 있음 |
| 레벨테스트 준비 안내 | FAQ에 "과정별로 다르니 문의하라"뿐 |
| 수료 후 고용 유지 추적 | 취업률 수치 외 언급 없음 |
| 공고 데이터 기반 수요 분석 | 기업 600곳 설문 조사만 있음 (새싹 소개 페이지) |
| "AI 인재 양성 종합 플랫폼"의 구체 기능 | 비전만 있고 기능과 일정 없음 |

### 근거 3. 수강생 목소리 (수강후기 849건)
| 관찰 | 수 |
|---|---|
| 시작 전 "따라갈 수 있을까" 걱정 | 177건 |
| 사전 지식 부족 언급 | 59건 |
| 진도가 빠름 | 52건 |
| 수료생이 "미리 공부하고 오라"고 조언 | 반복 (상세는 user-research 문서) |

### 정리한 사각지대
SeSAC은 입과 후 교육과 취업 연계에 집중하고 있고, **지원 전 단계**(내가 어떤 과정에 맞는지, 무엇을 먼저 채워야 하는지)는 비어 있습니다. 2.0에서 탈락 기준이 오르고 재참여 제한이 생기면서 이 빈 곳의 비용이 커졌습니다. 기관 쪽에서는 **현장 수요를 실제 공고 데이터로 확인하는 장치**가 없습니다.

## 4. 일로가 정책 목표에 연결되는 지점

| SeSAC 정책 목표 또는 지적 | 지금 상태 | 일로가 하는 일 | 일로 화면 |
|---|---|---|---|
| 일자리 미스매치 해소 (정책 목적) | 기업 설문 중심 | 실제 공고에서 요구 역량을 집계 | 역량 표, 수요가 늘어나는 역량 |
| 교육생 80~90% 양질의 취업 (2.0 목표) | 선발 후 교육 | 지원 전에 직무와 과정 적합도를 보여줘 맞는 과정으로 들어가게 함 | 진단 결과, 준비 순서 |
| 중도 탈락 기준 80점 (2.0) | 입과 후 대응 | 부족 역량을 미리 채우는 준비 순서 | 준비 순서, 주차별 할 일 |
| 현장 수요와 괴리 (시의회) | 반기별 교육파트너 모집 | 과정 커리큘럼과 공고 요구 역량 비교, 개편 제안 | 기관 대시보드, SeSAC 과정 화면 |
| 학과 운영위원회의 과정 신설과 폐지 (2.0) | 근거 자료 형식 없음 | 직무별 수요 변화와 과정별 커버리지 리포트 | 기관 대시보드 |
| AI 인재 양성 종합 플랫폼 (시장 비전) | 기능 미정 | 플랫폼의 "지원 전 진단" 모듈로 제안 | 전체 |

## 5. 기대 효과와 성과지표 제안

| 지표 | 정의 | 왜 이 지표인가 |
|---|---|---|
| 진단 후 지원 전환율 | 진단을 마친 사람 중 SeSAC에 지원한 비율 | 일로가 지원을 늘리는지 |
| 레벨테스트 통과율 차이 | 일로 사용자와 비사용자 비교 | 준비 순서가 효과 있는지 |
| 초반 중도 탈락률 | 입과 후 4주 안 탈락 비율 | 2.0의 80점 기준과 직접 연결 |
| 과정 적합도 | 수료생 취업 직무와 진단 직무 일치율 | 미스매치 해소 |
| 6개월 고용 유지율 | 시의회가 요구한 지표 | 일로가 직접 측정하긴 어렵지만, 맞는 과정 선택이 유지율을 높인다는 가설로 제시 |

마지막 지표는 해커톤 기간에 검증할 수 없습니다. 발표에서는 "장기적으로 이 지표에 기여할 것"으로만 말하고, 수치를 약속하지 않습니다.

## 6. 보강 시트 3번 초안

> **연계 정책**: 서울시 청년취업사관학교 새싹(SeSAC), 경제실 일자리정책과
>
> **정책 목표**: 청년 AI 인재를 키워 구직 청년과 기업 사이의 일자리 미스매치를 줄이고, 2.0 프로젝트에 따라 교육생의 80~90%를 양질의 일자리로 연결
>
> **연계 방식**: SeSAC은 입과 후 교육과 취업 지원에 집중하지만, 지원 전 단계에서 청년이 자기 역량과 과정의 적합도를 확인할 방법이 없다. 일로는 실제 채용 공고를 기준으로 부족 역량과 준비 순서를 보여주고 맞는 SeSAC 과정으로 연결한다. 같은 공고 데이터로 서울시와 SeSAC에 직무별 역량 수요 변화를 제공해, 시의회가 지적한 현장 수요와의 괴리를 줄이는 근거 자료로 쓰게 한다.
