## 3. 인사이트

각 인사이트는 관찰, 해석, 인사이트, 시사점을 나눠 적었습니다.

### 인사이트 1. 지원자는 "내가 따라갈 수 있을까"를 판단할 근거 없이 지원한다
| 구분 | 내용 |
|---|---|
| 관찰 | 후기 177건이 시작 전 걱정을, 196건이 비전공 배경을 언급. 사전 지식을 미리 알려주는 공식 안내는 FAQ에 "과정별로 다르니 문의하라"뿐 |
| 해석 | 지원자는 스스로 준비 수준을 판단하지 못하고, 일단 넣고 보는 방식으로 결정하는 것으로 보임 |
| 인사이트 | 지원 결정의 가장 큰 불확실성은 과정 정보가 아니라 "내 현재 수준이 이 과정에 맞는가"일 가능성이 높음 |
| 신뢰도 | 중간. 수료생이 회고한 걱정이라, 실제 지원 시점의 판단 과정은 직접 확인 필요 |
| 시사점 | 일로의 첫 화면 메시지를 "과정 추천"보다 "지금 내 수준 진단"에 두는 방향을 테스트 |

### 인사이트 2. 어려움은 입과 후 초반에 몰리고, 사전 준비 조언은 수료생끼리만 돈다
| 구분 | 내용 |
|---|---|
| 관찰 | 진도 52건, 사전 지식 59건. "예습하고 오라", "기초를 알고 가라"는 조언이 후기 안에 반복 |
| 해석 | 무엇을 먼저 공부해야 하는지는 수료 후에야 알게 되는 정보 |
| 인사이트 | 수료생이 아는 "이 과정 전에 필요한 것"을 지원 전에 보여주면 가치가 큼 |
| 신뢰도 | 중간. 여러 연도와 과정에서 반복되지만 후기 게시판 하나의 출처 |
| 시사점 | 준비 순서 화면에 "이 과정 수료생이 미리 하라고 한 것"을 근거로 함께 보여주는 안 |

### 인사이트 3. 레벨테스트와 면접은 체감 난이도가 사람마다 크게 다르다
| 구분 | 내용 |
|---|---|
| 관찰 | 블로그 3건 중 1건은 "간단", 1건은 "생각보다 어려움, 기본 개념 답 못함" |
| 해석 | 과정마다 테스트가 다르고 정보가 없음 |
| 인사이트 | 가설 단계. 레벨테스트 대비가 실제 니즈인지 아직 모름 |
| 신뢰도 | 낮음. 3건뿐 |
| 시사점 | 11/3 테스트에서 직접 물어볼 질문 1순위 |

### 인사이트 4. "무료"가 지원 동기라서 과정 선택이 덜 신중할 수 있다
| 구분 | 내용 |
|---|---|
| 관찰 | 무료 언급 64건, "일단 해보자" 류 69건 |

## 5. 11/3 사용자 테스트 계획

| 항목 | 내용 |
|---|---|
| 목적 | 인사이트 1~4 검증, 프로토타입의 진단 흐름이 이해되는지 확인 |
| 방법 | 1:1 인터뷰 20분 + 프로토타입 과제 15분, 총 35분 |
| 인원 | 5~6명. 페르소나 A 3명 이상, B 또는 C 2명 |
| 장소 | 대면 또는 Zoom (화면 공유) |
| 진행 | 진행자 1명, 기록자 1명 |
| 기록 | 동의 받고 녹음. 이름 대신 P1, P2로 기록 |
| 인센티브 | 기프티콘 등 (팀 예산 확인) |

### 모집 기준 (스크리너)
| 질문 | 통과 조건 |
|---|---|
| 지난 1년 안에 국비, 부트캠프, SeSAC 과정을 찾아보거나 지원한 적이 있나요? | 예 |
| 현재 상황은? (재학, 졸업 후 구직, 재직, 기타) | 재학 고학년 또는 구직 중 |
| 전공은? | A는 비IT 전공, C는 IT 전공 |
| SeSAC에 지원해본 적이 있나요? 결과는? | 합격, 탈락, 검토만 함 골고루 섞기 |
| 지원을 고민하다 안 한 적이 있나요? | 있으면 우선 |

제외: 팀원 지인 중 일로 아이디어를 이미 들은 사람, IT 현업자.

### 인터뷰 질문지

**도입 (2분)**
"오늘은 서비스를 평가받는 자리가 아니라, 교육 과정을 고를 때 어떤 경험을 하셨는지 듣는 자리예요. 정답은 없고, 솔직한 이야기가 가장 도움이 됩니다."

**최근 경험 (10분)**
1. 가장 최근에 교육 과정이나 부트캠프를 찾아본 때를 떠올려 주세요. 언제, 왜 찾기 시작하셨나요?
2. 그때 어떤 순서로 찾아보셨어요? 어디서 보셨나요?
3. 여러 과정 중 하나를 고를 때 무엇을 보고 결정하셨나요?
4. 그 과정을 따라갈 수 있을지는 어떻게 판단하셨나요? (판단 못 했다면) 그때 어떻게 하셨어요?
5. 레벨테스트나 면접을 준비하신 적이 있나요? 무엇을 했고, 정보는 어디서 얻으셨어요?

**어려움 (5분)**
6. 과정을 고르거나 지원하면서 가장 답답했던 순간은 언제였나요?
7. 지원했다가 포기하거나, 떨어지거나, 들어가서 힘들었던 경험이 있나요? 그때 무엇이 있었으면 달랐을까요?
8. SeSAC 오프라인 과정은 최대 2번만 들을 수 있다는 걸 알고 계셨나요?

**지금 방식 (3분)**
9. 지금 내 역량이 원하는 직무에 비해 어느 정도인지 확인해본 적이 있나요? 어떻게요?

### 프로토타입 과제 (15분, 생각을 말하면서 진행)
| 과제 | 성공 기준 | 관찰할 것 |
|---|---|---|
| 1. 이력서를 올리고 분석을 시작해 보세요 | 2분 안에 결과 화면 도달 | 업로드 망설임, 개인정보 걱정 |
| 2. 결과에서 지금 가장 먼저 준비할 것을 찾아 말해 주세요 | 1순위 역량을 정확히 말함 | 순위 근거(공고 수)를 이해하는지 |
| 3. 그 역량을 채울 SeSAC 과정을 골라 보세요 | 과정 카드까지 이동 | 과정 정보 중 무엇을 보는지 |
| 4. 이 결과를 믿을 수 있나요? 왜 그런가요? | 이유를 말함 | 근거 공고를 열어보는지 |

**마무리 질문**
10. 이 결과를 받는다면 다음에 무엇을 하시겠어요?
11. 지원 전에 이걸 봤다면 달라졌을 것이 있을까요?

### 질문할 때 피할 것
"이 기능 좋으세요?", "쓸 의향 있으세요?" 같은 미래 의향 질문은 하지 않습니다. 과거에 실제로 한 행동을 묻습니다.

### 분석 방법
| 단계 | 내용 |
|---|---|
| 1 | 세션마다 행동, 발언, 불편, 대안 행동, 해석을 따로 기록 |
| 2 | 인사이트 1~4 각각 "맞다 / 아니다 / 불분명"을 참가자별로 표시 |
| 3 | 과제 성공률과 막힌 지점을 화면별로 정리 |
| 4 | 인사이트별로 "6명 중 몇 명" 형태로 보고 |
