# 일로 (illo)

내 경험이 공고의 어떤 문장과 이어지는지 보여 주고, 비어 있는 부분을 SeSAC 과정과 청년 정책으로 이어 주는 서비스입니다.

- 프로토타입: https://illo-prototype.vercel.app (휴대폰은 모바일 화면, PC는 데스크톱 화면)
- 디자인 캔버스: https://claude.ai/artifact/YL34ZfQJf3ggkFZz1JH2Er (팀원에게 공유 필요)

## 시연 흐름 (2분)

홈, 직무 찾기, 공고 고르기, AI 비교, 다음 행동 고르기 (교육, 자격증, 대외활동, 지원 준비), 마이페이지 저장.
