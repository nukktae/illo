# P04 PRD 검증 기록

검토일 2026.11.01 · 대상 [P04 PRD v1.2](../prd/P04-education.md) · 담당 이민섭

**판정: P04 내부 요구사항은 구체화 완료. 팀 승인·연계 Spec·데이터 준비는 미완료.** 기능 19개와 수용 기준 42개로 Spec 작성 입력을 정리했다. 공통 인증·저장·비교 문맥 계약이 없으므로 이 문서만으로 통합 개발 준비가 끝났다고 판단하지 않는다.

## 1. 검증 범위

- 사용자가 확정한 범위·역할·로그인 후 저장 조건과 PRD 일치 여부.
- P01~P06·00-root·PRD/Spec 작성 가이드와 페이지 간 요구사항 대조.
- 교육 CSV 210개, 화면용 과정 JSON 210개, 정책 원본 1,476개와 화면용 213개의 필드·상태·식별자 확인.
- 데이터 변환 코드, 교육·다음 행동·공통 저장·시연 로그인 화면 소스 검토.
- 대표 SeSAC 공식 상세와 온통청년 공식 코드 정의서 확인.

브라우저 사용성 테스트·실제 로그인·저장·API 기능 테스트는 수행하지 않았다. 이번 변경은 PRD와 검증 기록이며 데이터·프로토타입 동작은 수정하지 않았다.

## 3. 원본 대조 수치

### 교육

- 원본·화면용 자료 모두 210개, 화면용 식별자 중복 0건.
- 원본 상태: 모집 중 15, 모집 예정 7, 운영 중 30, 운영 대기 1, 종료 144, 상시 13.
- 모집 중 15건의 수집본 모집 기간은 2026.11.01을 포함한다. 공식 사이트 15건을 실시간 전수 확인한 결과는 아니다.
- 현재 화면용 자료는 모집 시작일을 보존하지 않는다. 전체 상세와 추천 근거를 추가 조사해야 한다.
- `edu-1421`만 대표 공식 상세로 확인했다. 기간·시간·교육 내용 구조를 확인했으며 나머지 14건의 상세 검수를 완료했다는 뜻은 아니다. [SeSAC 공식 과정](https://sesac.seoul.kr/sesac/course/offline/courseDetail.do?crsSn=1421)

### 정책

213개 화면용 정책 모두 원본의 `plcyNo`로 연결되며 식별자 중복은 없다.

| 구분 | 기존 화면 자료 | 원본 코드·신청 기간 대조 |
| --- | --- | --- |
| 신청 중 | 12 | 12 |
| 상시 | 121 | 38 |
| 마감 | 80 | 163 |
| 합계 | 213 | 213 |

공식 코드 의미는 특정기간 `0057001`, 상시 `0057002`, 마감 `0057003`이다. 기간이 없는 121건 중 83건이 마감 코드인데도 기존 변환 코드에서 상시로 분류된다. 이는 실제 변환 오류다. 대조 결과의 신청 중·상시 50건도 현재 예산 소진·별도 종료 여부까지 확인한 결과는 아니다. [온통청년 공식 코드 정의서](https://www.youthcenter.go.kr/downloadform/API%EC%BD%94%EB%93%9C%EC%A0%95%EB%B3%B4.xlsx)

- 원본 직접 신청 URL 누락 116건, 신청 방법 누락 79건.
- 원본에는 쉼표로 여러 분야가 기재된 항목 5건이 있다. 같은 분야가 반복된 2건과 서로 다른 분야를 가진 3건을 구분해 중복 제거해야 한다.
- 기관 분류는 현재 제공 자료의 등록기관명 기반이다. 이를 개인의 거주 자격이나 중앙 정책의 전국 신청 가능으로 해석하면 안 된다.

## 5. Spec 작성자가 바로 사용할 입력

1. PRD 1~3절: 목표·대상·범위.
2. 4~10절: 진입·상태 전이·검색/정렬·상세·저장·실패 동작.
3. 11절: 논리 데이터·기존 자료·보강 필드·검수 조건.
4. 12절: 기능과 연결된 수용 기준 42개.
5. 13절: 담당자 계약·차단 사항 G01~G07·시작 체크리스트.

가장 먼저 해결할 것은 **G01~G03의 페이지 간 계약**, **G05의 상세·추천 근거 자료**, **G06의 정책 상태 오분류**다. 미결 사항을 임의의 DB·인증 방식·예시 추천으로 메우지 않는다.
