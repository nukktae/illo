# P06 로그인과 회원가입 PRD

버전 v1.1 초안 (2026.11.02) | 상위 문서: [00-root.md](00-root.md) | 이번 범위: 화면과 흐름만

## 1. 요약

로그인하면 저장함과 이력서를 어디서든 이어서 본다. 상단 오른쪽이 로그인 전에는 로그인과 회원가입, 로그인 뒤에는 저장함 아이콘과 이름으로 바뀐다.

## 2. 왜 필요한가

- 저장, 이력서, 내 경로는 계정이 있어야 기기를 바꿔도 남는다.
- 로그인 여부에 따라 홈 인사가 달라진다.

## 3. 하지 않는 것

- 11/6 범위에서 실제 인증 서버, 비밀번호 찾기, 탈퇴는 만들지 않는다. 시연용으로 아무 값이나 넣으면 예시 계정으로 로그인된다.

## 4. 기능 요구사항

| ID | 기능 | 설명 | 범위 |
|---|---|---|---|
| P06-F01 | 상단 상태 | 로그인 전: 로그인, 회원가입. 로그인 뒤: 저장함 아이콘 (개수), 프로필 사진과 이름 (데스크톱은 김하늘 프로필 사진, 모바일은 첫 글자) | MVP |
| P06-F02 | 로그인 | 카카오, 네이버, Google, 이메일과 비밀번호 | 화면 |
| P06-F03 | 회원가입 | 소셜, 이름, 이메일, 비밀번호, 지금 상태 (재학생, 취업 준비생, 재직자), 관심 직무, 약관 동의 | 화면 |
| P06-F04 | 가입 뒤 이동 | 가입하면 이력서 등록으로 바로 간다 | MVP |
| P06-F05 | 실제 인증 | Supabase Auth (카카오, Google) | 다음 |

## 5. 수용 기준

- **Given** 로그인 전 **When** 로그인 버튼을 누르면 **Then** 홈 상단에 "김하늘님"과 저장함 개수가 보인다.
- **Given** 회원가입에서 **When** "가입하고 이력서 등록하기"를 누르면 **Then** 이력서 등록 화면으로 간다.

## 6. 화면

캔버스 L1 로그인, L2 회원가입. 프로토타입 `/L1-login.html`, `/L2-signup.html`

## 7. 로그인 뒤 돌아가기

- 로그인이 필요한 화면 (마이페이지 한눈에 보기, 저장함, 이력서 등록)에 로그인하지 않고 오면 로그인 화면으로 보내고 주소에 원래 화면을 붙인다 (`L1-login.html?next=S5-path.html`). 시연용 로그인을 누르면 원래 화면으로 돌아간다. `next`가 없으면 홈으로. 11/6은 데스크톱만 (P05-F23).
