# P01 홈 PRD

버전 v1.0 초안 (2026.11.01) | 상위 문서: [00-root.md](00-root.md)

## 1. 요약

처음 들어온 사람이 무엇을 하는 서비스인지 바로 알고, 직무 검색이나 핫 공고로 시작하게 한다. 실시간 공고 키워드로 관심을 끈다.

## 2. 왜 필요한가

- 10/30 팀 회의: 홈에 정보가 너무 많아서 무엇이 핵심인지 안 보였다. 설명을 줄이고 영역을 분명히 나눈다.
- 실시간 키워드는 이목을 끄는 장치다. 핵심 기능은 아니므로 작게 둔다.

## 3. 목표

- 3초 안에 "공고와 내 경험을 AI로 비교하는 곳"이라는 걸 안다.
- 첫 행동 (검색, 직무 칩, 핫 공고 비교하기) 중 하나를 누른다.

## 4. 하지 않는 것

- 홈에서 비교 결과나 긴 설명을 보여 주지 않는다.
- 로그인한 사람마다 다른 추천을 만들지 않는다 (인사 문구만 바뀐다).

## 5. 기능 요구사항

| ID | 기능 | 설명 | 범위 |
|---|---|---|---|
| P01-F01 | 상단 메뉴 | 홈, 직무 찾기, 교육과정, 마이페이지. 오른쪽에 로그인, 회원가입 또는 저장함과 이름 | MVP |
| P01-F02 | 첫 화면 | "청년의 경험으로, 다음 청년의 기회를", 한 줄 설명, 직무 검색, 많이 찾는 직무 7개 | MVP |
| P01-F03 | 직무 칩 | 누르면 직무 찾기에서 그 직무 목록이 열린다 | MVP |
| P01-F04 | 실시간 공고 키워드 | SNS 콘텐츠 마케팅 TOP 5, 순위 변화. "전체 보기"는 팝업 (TOP 8, 자격증 3% 등) | MVP |
| P01-F05 | 이번 주 핫 공고 | 3개. 시연 공고만 비교하기 버튼, 저장 버튼 | MVP |
| P01-F06 | 로그인 인사 | 로그인하면 "김하늘님, 저장함에 N개가 있어요" | 시연 |

## 6. 예외와 빈 상태

| 상황 | 처리 |
|---|---|
| 검색어가 7개 직무에 없음 | 직무 찾기로 가서 "아직 준비 중인 직무예요" |
| 키워드 데이터 없음 | 키워드 영역을 숨긴다 |

## 7. 수용 기준

- **Given** 처음 온 사람이 **When** 홈을 열면 **Then** 첫 화면에 검색창과 직무 칩 7개가 보인다.
- **Given** 홈에서 **When** "데이터 분석" 칩을 누르면 **Then** 직무 찾기가 데이터 분석 목록으로 열린다.
- **Given** 홈에서 **When** 키워드 "전체 보기"를 누르면 **Then** 팝업에 8개 순위와 출처가 보인다.
