# P01 홈 PRD

버전 v1.1 초안 (2026.11.02) | 상위 문서: [00-root.md](00-root.md) | 상태: 팀 검토 전

## 1. 요약

처음 온 사람이 3초 안에 "공고 문장마다 내 경험을 비교해 주는 곳"이라는 걸 알고, 버튼 하나로 시연 공고 비교를 시작한다. 로그인한 사람은 하던 일 (이어서 비교, 저장함, 이력서)로 바로 돌아간다.

## 2. 왜 필요한가

- 10/30 팀 회의: 홈에 정보가 너무 많아서 무엇이 핵심인지 안 보였다. 설명을 줄이고 영역을 분명히 나눈다.
- 11/2 전체 리뷰 (전략, UX, 화면 설계):
  - 검색창은 입력한 말을 쓰지 않고 항상 같은 목록으로 간다. 동작하지 않는 입력은 믿음을 깎는다.
  - 파란 버튼이 두 개 (찾아보기, 비교하기)라 주요 행동이 하나로 안 보인다.
  - 실시간 키워드가 핫 공고보다 먼저, 같은 크기로 나온다. 키워드는 이목을 끄는 장치일 뿐 핵심 기능이 아니다.
  - 핫 공고 3개 중 1개만 비교로 이어지고 2개는 흐리게 막혀 있다.
  - 홈 어디에도 이 서비스의 핵심인 "공고 문장과 내 경험 비교"가 보이지 않는다.
  - 로그인해도 저장함 알림 한 줄만 바뀌어 하던 일로 돌아갈 길이 없다.
- 11/6까지는 백엔드 없이 프론트엔드로만 만든다. 로그인과 저장은 이 기기 브라우저에만 남는다.

## 3. 목표

- 3초 안에 "공고 문장마다 내 경험을 비교해 주는 곳"이라는 걸 안다.
- 첫 화면에서 누를 주요 행동은 하나다: "시연 공고로 비교해 보기".
- 비교 예시를 보고 맞음, 일부, 없음이 무슨 뜻인지 대략 안다.
- 로그인한 사람은 한 번에 비교 결과, 저장함, 이력서로 돌아간다.

## 4. 하지 않는 것

- 홈에 직무 검색창을 두지 않는다. 검색은 직무 찾기 (P02)에서 한다.
- 홈에서 실제 비교를 실행하거나 개인 비교 결과를 보여 주지 않는다. 예시 한 장만 보여 준다.
- 로그인한 사람마다 다른 공고 추천을 만들지 않는다.
- 합격 가능성, 점수, 순위를 보여 주지 않는다.

## 6. 예외와 빈 상태

| 상황 | 처리 |
|---|---|
| 로그인하지 않음 | F06을 숨긴다. 첫 화면은 F02부터 시작한다 |
| 로그인했지만 비교한 공고가 없음 | F06의 첫 링크를 "시연 공고 비교해 보기"로 바꾼다 |
| 저장한 게 없음 | F06의 저장함 링크를 "저장함 0개"로 그대로 둔다 |
| 핫 공고가 시연 공고가 아님 | "비교 준비 중"을 보여 주고 비교 화면으로 보내지 않는다. 저장은 된다 |
| 키워드 데이터 없음 | 키워드 영역을 숨긴다 |
| 브라우저 저장이 막힘 (시크릿 모드 등) | 로그인하지 않은 상태로 보여 준다 |

- 비교 예시: 시연 공고 원문과 비교 화면 (`design/screens/30_compare.py`의 `POST_REQ`)의 요구와 근거를 짧게 줄여 쓴다. 없는 내용을 지어내지 않는다.
- 키워드: SNS 콘텐츠 마케팅 2026 공고 59건 기준 (출처 한 줄로 표시).
- 로그인과 이름: 브라우저 `illo-user`. 저장함 개수: 브라우저 `illo-saved`.

## 8. 수용 기준

- **Given** 처음 온 사람이 **When** 홈을 열면 **Then** 첫 화면에 제목 "공고 문장마다, 내 경험을 비교해요"와 파란 버튼 "시연 공고로 비교해 보기" 하나가 보이고, 검색창은 없다.
- **Given** 홈에서 **When** "시연 공고로 비교해 보기"를 누르면 **Then** 올리브인터내셔널 공고 비교 화면이 열린다.
- **Given** 홈 첫 화면에서 **Then** 비교 예시에 맞음 1개와 없음 1개가 한 줄 근거와 함께 보이고, AI 배지와 "시연 예시" 표시가 있다.
- **Given** 홈에서 **When** "데이터 분석" 칩을 누르면 **Then** 직무 찾기가 데이터 분석 목록으로 열린다.
- **Given** 홈의 핫 공고에서 **Then** 시연 공고에는 "비교하기", 나머지 두 개에는 "비교 준비 중"이 보이고, 세 공고 모두 흐리지 않다.
- **Given** 홈에서 **Then** 실시간 키워드는 핫 공고 아래에 있고 LIVE 표시가 없다.
- **Given** 홈에서 **When** 키워드 "전체 보기"를 누르면 **Then** 팝업에 8개 순위와 출처가 보인다.
- **Given** 시연용 로그인을 한 뒤 **When** 홈을 열면 **Then** 맨 위에 "김하늘님, 이어서 볼까요?"와 비교 결과, 저장함 N개, 이력서 수정 링크가 보인다.
- **Given** 로그인하지 않은 상태에서 **When** 홈을 열면 **Then** 이어서 하기 줄이 보이지 않는다.
- **Given** 홈 어디에서도 **Then** 합격, 확률, 점수라는 말이 없다.
