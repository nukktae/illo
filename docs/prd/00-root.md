# 일로 전체 PRD (루트)

버전 v1.0 초안 (2026.11.01) | 상태: 팀 검토 전 | 이 문서는 지도 역할만 하고, 자세한 내용은 페이지별 PRD에 있다.

## 1. 한 줄 요약

청년이 지원하고 싶은 공고와 내 경험을 문장 단위로 비교해 보고, 비어 있는 부분을 SeSAC 과정, 자격증, 대외활동, 지원 준비 중에서 직접 골라 채우게 돕는다.

## 2. 문제

- 취업 준비생은 내 경험이 공고의 어떤 요구와 이어지는지 모른다. 동아리, 학생회 SNS 운영 같은 경험은 쓸모가 있는지 판단하기 어렵다.
- 고용24 잡케어는 SNS 마케터 직무가 없고, 동아리 경험을 점수로 반영하지 못하며, 추천 공고 50개 중 마케팅은 4개였다 (팀 직접 사용, 10/29).
- SeSAC 같은 좋은 정책이 있어도, 내 빈 칸을 채우는 과정인지 알기 어렵다.
- 공고는 자격증보다 직접 만든 결과물을 본다. SNS 콘텐츠 마케팅 공고 104건 중 자격증을 적은 공고는 3%다.

## 3. 대상

- **주 페르소나 (시연)**: 학생회 홍보부에서 인스타그램을 1년 운영한 취업 준비생. 미디어커뮤니케이션학과, 컴활 2급, OPIc IM2. SNS 콘텐츠 마케터 신입이나 인턴을 준비한다.
- **함께 쓰는 사람**: 재학생 1~3학년 (탐색), 이직을 준비하는 신입 마케터 (공고 비교).
- 발표는 주 페르소나 한 명으로 끝까지 보여 준다. 다른 직무도 같은 파이프라인으로 확장된다고 설명한다.

## 4. 핵심 기능 3가지

1. **공고와 내 경험 비교 (AI)**: 공고 원문 문장마다 내 경험의 근거 문장을 찾아 맞음, 일부, 없음으로 표시한다. `P03`
2. **다음 행동 고르기**: 비어 있는 것을 교육, 자격증과 어학, 대외활동과 프로젝트, 지원 준비 중에서 사용자가 고른다. `P03`, `P04`
3. **정책 연결**: SeSAC 과정 210개와 청년 일자리 정책 213건을 내 빈 칸 기준으로 보여 준다. `P04`

## 5. 목표와 성공 지표

| 지표 | 목표 | 확인 방법 |
|---|---|---|
| AI 근거 추출 정확도 | 90% 이상 | 공고와 경험 짝 50건을 사람이 직접 검수 (11/3 전) |
| 시연 흐름 이해도 | 테스트 참가자 5명 중 4명 이상이 도움 없이 끝까지 진행 | 11/3 사용자 테스트 |
| 다음 행동 선택률 | 비교 결과를 본 사람의 절반 이상이 다음 행동 하나를 누름 | 사용자 테스트 관찰 |

## 6. 하지 않는 것 (비목표)

- 합격 여부나 합격 확률을 예측하지 않는다.
- AI가 대신 결정하지 않는다. 추천은 하되 고르는 건 사용자다.
- 11/6 제출 범위에서 실제 회원 계정, 결제, 기관용 대시보드는 만들지 않는다.
- 모든 직무의 역량 분석을 하지 않는다. 역량 분석은 SNS 콘텐츠 마케팅만, 나머지 6개 직무는 공고 목록만.
