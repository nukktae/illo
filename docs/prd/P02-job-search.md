# P02 직무 찾기 PRD

버전 v1.0 초안 (2026.11.01) | 상위 문서: [00-root.md](00-root.md)

## 1. 요약

직무를 고르고, 그 직무의 공고 목록에서 비교할 공고를 고른다. 신입과 인턴에게는 내 경험으로 본 직무 역량을 먼저, 경력에게는 공고 비교를 바로 보여 준다.

## 2. 왜 필요한가

- 10/30 회의: 신입과 인턴은 어떤 직무가 맞는지부터 알고 싶고, 경력자는 고른 공고와 바로 비교하고 싶다.
- 공고는 실제로 100건이 넘는다. 검색, 필터, 정렬, 페이지가 필요하다.

## 3. 목표

- 7개 직무 중 하나를 골라 공고 목록을 본다.
- 공고 하나를 골라 P03 비교로 간다.

## 4. 하지 않는 것

- SNS 콘텐츠 마케팅 외 6개 직무의 역량 분석, 공고 비교 (이번 범위 밖, "준비 중" 표시)
- 경력 공고 목록 (이번 범위 밖)

## 5. 기능 요구사항

| ID | 기능 | 설명 | 범위 |
|---|---|---|---|
| P02-F01 | 직무 고르기 | 7개 직무 칩과 "다른 직무 검색". 없는 직무는 "아직 준비 중이에요" | MVP |
| P02-F02 | 신입, 경력 전환 | 신입과 인턴은 역량 카드, 경력은 안내 카드 | MVP |
| P02-F03 | 역량 카드 (AI) | 공고가 많이 찾는 역량 8개를 칩으로, 내 이력서에 있는 것은 체크. SNS 콘텐츠 마케팅만 | MVP |
| P02-F04 | 공고 검색 | 회사명, 공고 제목 | MVP |
| P02-F05 | 필터, 정렬 | 전체, 인턴, 신입 / 추천순 (겹치는 역량 많은 순), 최신순, 마감 임박순 | MVP |
| P02-F06 | 목록, 페이지 | 10개씩, 페이지 번호. 행마다 회사, 제목, 태그, D-day, 저장, 비교하기 또는 원문 | MVP |
| P02-F07 | 트렌드 팝업 | "이 직무 트렌드 보기" (SNS 콘텐츠 마케팅만) | MVP |

## 6. 예외와 빈 상태

| 상황 | 처리 |
|---|---|
| 검색 결과 없음 | "검색 결과가 없어요" 와 "검색어 지우기" |
| 마감일 없는 공고 | "상시, 채용 시 마감" |
| 비교 데이터가 없는 공고 | 비교하기 대신 "원문" 버튼 |

## 7. 데이터

- SNS 콘텐츠 마케팅: 2026 신입, 인턴 46건 (`design/data/posts2026.json`)
- 다른 6개 직무: 마감 전 공고, 직무별 최대 120건 (`design/data/jobs_other.json`)

## 8. 수용 기준

- **Given** 직무 찾기에서 **When** "AI 엔지니어"를 누르면 **Then** 제목이 바뀌고 그 직무 공고가 10개씩 보인다.
- **Given** 목록에서 **When** "마감 임박순"을 누르면 **Then** D-day가 작은 공고가 위로 온다.
- **Given** "회계"를 직무 검색하면 **Then** "아직 준비 중이에요"가 보인다.
