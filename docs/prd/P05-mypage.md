# P05 마이페이지 PRD

버전 v1.0 초안 (2026.11.01) | 상위 문서: [00-root.md](00-root.md) | 이력서 입력은 P03 비교의 입력이라 함께 구현

## 1. 요약

이력서를 한 번 등록하면 공고마다 다시 입력하지 않는다. 저장한 공고, 과정, 정책을 모아 보고, 내 취업 경로와 취업 수기를 남긴다. 탭은 한눈에 보기, 저장함, 이력서 등록.

## 2. 왜 필요한가

- 10/30 회의: 공고마다 경험을 다시 쓰는 건 불필요하다. 마이페이지에 저장하고 비교에 재사용한다.
- 저장 기능 요청: 공고, 교육과정, 정책을 저장하고 한곳에서 본다.
- 선순환: 취업 후 수기를 남기면 다음 청년의 추천 근거가 된다.

## 3. 목표

- 이력서 15개 항목 중 필요한 것을 빠르게 채운다 (PDF를 올리면 AI가 채움).
- 저장한 것을 다시 찾아 비교나 신청으로 이어 간다.

## 4. 하지 않는 것

- 이력서를 기업에 보내지 않는다.
- 이번 범위에서 계정 서버 저장은 하지 않는다 (프로토타입은 브라우저에만 저장).

## 5. 기능 요구사항

| ID | 기능 | 설명 | 범위 |
|---|---|---|---|
| P05-F01 | 탭 | 한눈에 보기, 저장함 (개수), 이력서 등록 | MVP |
| P05-F02 | 이력서 15개 항목 | 인적사항, 희망 직무, 스킬, 학력, 경력 (신입 체크), 인턴과 대외활동, 교육, 자격증, 수상, 해외 경험, 어학, 포트폴리오, 취업 우대와 병역, 자기소개서, 희망 근무 조건 | MVP |
| P05-F03 | 진행 사이드바 | 15개 중 N개 작성, 항목별 체크, 누르면 그 항목으로 이동, 저장 버튼 | MVP |
| P05-F04 | 빈 선택 항목 접기 | 교육, 수상, 해외 경험, 취업 우대는 한 줄로 접어 두고 "+ 추가" | MVP |
| P05-F05 | PDF로 채우기 (AI) | 이력서 PDF를 올리면 AI가 항목을 나눠 채우고 사용자가 확인 | 다음 |
| P05-F06 | 공고 데이터 힌트 | 항목 옆에 공고 근거 (자격증 3%, 외국어 14%, 툴 언급 건수) | MVP |
| P05-F07 | 저장함 | 전체, 공고, 교육, 정책 필터. 공고는 "내 경험과 비교", 과정과 정책은 "자세히" 또는 "열기", 저장 해제, 빈 상태 | MVP |
| P05-F08 | 내 취업 경로 | 목표 공고, AI 비교 결과, 고른 다음 행동, 그다음 | 시연 |
| P05-F09 | 취업 수기 | 합격 직무, 도움 된 과정과 경험, 한마디. 다음 청년 화면에 어떻게 보이는지 미리보기 | 시연 |

## 6. 예외와 빈 상태

| 상황 | 처리 |
|---|---|
| 저장한 게 없음 | "아직 저장한 게 없어요" 와 공고 보기, 교육과정 보기 버튼 |
| 필수 항목 비어 있음 | 사이드바에서 빈 원으로 표시, 저장은 가능 |
| PDF 읽기 실패 | "읽지 못했어요. 직접 입력해 주세요" |

## 7. 수용 기준

- **Given** 이력서 등록에서 **When** 사이드바 "학력"을 누르면 **Then** 학력 카드로 이동한다.
- **Given** 공고를 저장한 뒤 **When** 저장함을 열면 **Then** 그 공고가 맨 위에 있고 "내 경험과 비교" 버튼이 있다.
- **Given** 저장함에서 **When** 저장 해제를 누르면 **Then** 목록과 상단 개수가 바로 줄어든다.
