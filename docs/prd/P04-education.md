# P04 교육과정과 정책 PRD

버전 v1.0 초안 (2026.11.01) | 상위 문서: [00-root.md](00-root.md)

## 1. 요약

SeSAC 과정 210개와 청년 일자리 정책 213건을 한곳에서 찾고 저장한다. 내 비교 결과의 빈 칸을 채울 수 있는 것부터 보여 준다.

## 2. 왜 필요한가

- 10/30 회의: 교육과 정책을 직무 찾기와 따로 볼 수 있는 영역이 필요하다. 공공 API로 SeSAC 말고도 여러 정책을 보여 준다.
- 정책 이름이 아니라 정책의 빈틈을 짚어야 한다 (사업기획 특강). 과정과 정책을 내 빈 칸과 연결한다.

## 3. 목표

- 과정이나 정책을 찾아 저장하거나 신청 페이지로 간다.
- 대표 한 건씩은 상세 페이지에서 자격과 신청 방법을 이해한다.

## 4. 하지 않는 것

- 일로 안에서 신청을 받지 않는다. 신청은 각 기관 사이트로 보낸다.
- 정책 데이터를 실시간으로 부르지 않는다 (11/1에 한 번 받아 저장).

## 6. 예외와 빈 상태

| 상황 | 처리 |
|---|---|
| 조건에 맞는 과정, 정책 없음 | "조건에 맞는 과정이 없어요" 와 "조건 지우기" |
| 과정 사진 없음 | 분야 색 블록과 캠퍼스 이름 |
| 정책 신청 기간 없음 | "상시 신청" |

## 7. 데이터

- SeSAC: `research/sesac/courses.csv` (210개), 후기 849건 (작성자 정보 제외)
- 정책: 온통청년 청년정책 API (`getPlcy`, 일자리 분야 1,476건 중 서울시, 중앙부처 213건). 키는 `.env`의 `YOUTH_POLICY_KEY`

## 8. 수용 기준

- **Given** 교육과정에서 **When** "마케팅" 칩을 누르면 **Then** 마케팅 분야 과정만 남고 개수가 맞게 바뀐다.
- **Given** 청년 정책 탭에서 **When** "서울시"와 "신청 가능만"을 누르면 **Then** 서울 정책 중 신청 중이거나 상시인 것만 보인다.
- **Given** 첫 정책 카드에서 **When** "자세히 보기"를 누르면 **Then** 정책 상세가 열리고 D-day와 신청 페이지 버튼이 보인다.
