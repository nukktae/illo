# P04 교육과정과 청년 정책 PRD

버전 v1.10 · 2026.11.04 · 담당 이민섭 · [전체 PRD](00-root.md)

## 1. 범위와 일정

11/6 제출은 백엔드 없는 프론트 시연이다. SeSAC / 청년 정책 두 탭만 제공하고 기본 진입은 SeSAC이다. 자격증·어학·대외활동은 P03 다음 행동에서 제공한다. 기능은 모두 시연 범위에 포함하며, 미리 준비한 자료로 검색·추천·상세·로그인 후 저장 흐름이 동작해야 한다.

본선 뒤 실제 인증·계정별 서버 저장·매일 자동 상태 확인·48시간 만료 운영을 설계한다. 11/6에는 자료 기준일을 표시하며 현재 실시간 상태·실제 계정 보안을 보장한다고 표현하지 않는다. 기준일은 실제 검수 시각이며 화면 조회·빌드 시각으로 바꾸지 않는다.

이번 개정은 PR 리뷰를 반영한 팀 작업 기준이다. 아래 시연 계약을 P03·P05·P06 담당과 공유하고, 실제 입력 예제·확인자·확인일을 Spec에 남긴다. 담당자 확인을 이미 받은 것으로 간주하지 않는다.

## 4. 주요 흐름

- 직접 탐색: SeSAC 전체 목록 → 검색·분야·상태 필터 → 과정 상세 → 저장 또는 공식 사이트.
- 비교 진입: P03의 완료된 시연 비교 결과 → 공고 보완/관심 학습 → 교육 근거 확인 → 비교 결과 복귀.
- 정책 탐색: 청년 정책 → 검색·기관·분야·신청 가능 필터 → 기존 P2 상세(지원 항목) 또는 공식 원문.
- 저장: 비로그인 북마크 → 시연 로그인 → 원래 항목·탭·조건 복귀 → 한 번 자동 저장 → P05 저장함.
- 저장함: 항목 ID로 해당 과정 상세나 정책 상세/공식 원문 이동. 마감됐어도 정보와 저장 해제는 제공한다.

## 5. 화면·검색·정렬

### 교육

- 전체 SeSAC 수집본 210개(오프라인 197·온라인 13)를 기본으로 표시한다. 모집 중·예정·진행 중·대기·종료·상시를 실제 자료 상태대로 표시한다. 전체 건수와 필터 결과 건수를 구분한다.
- 기존 ‘모집 중, 예정만’ 선택 필터를 유지하되 첫 진입은 꺼짐이다. 켜면 모집 중·예정만 표시하며 상시는 포함하지 않는다. 초기화하면 전체 과정으로 돌아온다.
- 신규 추천은 모집 중이며 기간과 근거가 확인된 과정 우선이다. 지난 과정은 일반 탐색에서 계속 볼 수 있다. P03의 ‘지난 과정 포함’ 51개는 해당 관련 과정 집합의 수로, 전체 210개와 다른 의미다. 51을 임의 고정하지 않고 실제 관련 집합에서 계산한다.
- 카드: 과정명·캠퍼스·분야·상태·모집 마감·교육 기간·저장·상세/공식 링크. 사진·후기 누락만으로 제외하지 않는다.
- 검색: 과정명·캠퍼스·분야·태그. 한글 조합 완료 후 적용. 분야는 전체·마케팅·AI·데이터·기획/PM·개발·디자인·기타 중 하나다.
- 필터·검색·정렬 후 데스크톱 9개/모바일 6개씩 표시한다. 조건 변경은 첫 페이지. 빈 결과는 초기화 안내와 구분한다.
- 정렬: 기본 모집 상태 우선(모집 중·예정·상시·진행/대기·종료), 같은 상태의 유효 모집 마감 오름차순, ID 순. 날짜가 없으면 같은 상태의 날짜 있는 항목 뒤다. 관련 역량순은 연결된 서로 다른 역량 수 내림차순 후 기본 순서를 적용한다. 후기순은 시연에 유지하되 추천 근거로 쓰지 않는다.
- 검색·분야 조건이 추천보다 우선한다. 탭 건수는 전체, 분야별 건수는 검색·상태 조건 적용 후, 목록 건수는 모든 조건 적용 후 계산한다.

### 정책

- 213건 전체 정책 중 기본 ‘신청 가능만’은 켜짐이다. 기준 자료에서 신청 중 12·상시 38로 50건이다. 끄면 마감·예정·확인 필요도 탐색한다. 숫자는 자료에서 계산하며 고정값으로 쓰지 않는다.
- 검색은 정책명·기관·전체 키워드·지원 내용. 기관 필터는 전체·서울시·중앙부처이며 거주 자격 판정과 다르다. 분야는 전체·취업·창업·재직자·권익보호. 복수 분야는 각 필터에 포함하되 목록에서 ID 중복 제거한다.
- 신청 중 → 상시 → 예정 → 확인 필요 → 마감 순. 신청 중 마감일·예정 시작일 우선, 나머지 동률은 ID 순. 10개씩 표시한다.
- 전체 보기·필터 해제는 검색·기관·분야를 유지하고 첫 페이지로 이동한다. 초기화는 신청 가능만 켜짐으로 복원한다. 탭 왕복에서는 직접 바꾼 조건을 유지한다.
- 기존 P2 내부 상세는 준비된 정책에 유지하고 그 외 항목은 해당 공식 원문으로 연결한다. 임의 정책을 대표 P2 내용으로 대체하지 않는다. 별도 목록 안 펼침은 이번 범위가 아니다.
- P05에서 특정 정책을 열면 필터 밖 항목도 정확한 ID의 상세/원문으로 이동한다. 대상 없음·조회 실패를 안내하고 저장함으로 돌아갈 수 있다.

## 6. 학습 목적·첫 진입·추천

#### 제공 범위와 목적

- 세부 학습 역량 선택·추천은 SNS·마케팅부터 제공한다. 모든 분야의 일반 탐색은 5절 교육, 공통 노출 제한은 9절, 지원 역량 정의·버전·검수·향후 확장 준비는 11절을 따른다.
- 추천할 과정의 분야는 마케팅으로 제한하지 않는다. AI·데이터·디자인 과정도 SNS·마케팅을 교육하는 검수 근거가 있으면 추천 가능하다. 비마케팅 분야 탐색에 SNS·마케팅 역량 선택을 요구하지 않는다.

| 목적 | 적용할 역량·필요한 입력 |
| --- | --- |
| 공고 보완 | 실제 P03 비교의 유효한 보완 후보 |
| 관심 학습 | 사용자가 직접 고른 학습 역량. 비교·보완 항목이 없어도 이용 가능하며 해당 역량이 부족하다는 뜻은 아님 |

두 목적은 교육 탭의 같은 목록·검색·필터·상세를 사용하며 전환 가능하다. 목적별 근거 표시는 7절, 선택·전환·전체 해제의 보존은 8절을 따른다.

#### 첫 진입 결정 순서

위에서부터 먼저 해당하는 규칙으로 기본 목적을 정한다. 지원 자격·능력 판정이 아니다. 새로고침·상세 복귀의 과거 진입값을 새 P03 선택으로 해석하지 않고 마지막 사용자 의도와 문맥 복원을 구분한다.

| 순서 | 확인된 조건 | 첫 화면·적용할 역량 |
| --- | --- | --- |
| 1 | 사용자가 P03에서 새로 교육 행동을 선택해 이번 진입의 명시적 공고 보완 선택을 전달 | 그 유효한 선택만 적용. 과거 P04 선택이나 신입/이직 기본값보다 이번 의도 우선 |
| 2 | 새 P03 선택 없이 같은 탐색/비교 문맥으로 복귀하며, 사용자가 목적·항목을 변경했거나 모두 해제한 기록 있음 | 직접 선택을 복원. 자동 기본값으로 덮어쓰지 않음. 모두 해제했다면 일반 목록 유지 |
| 3 | 현재 지원 목적이 경력 이직으로 확인됨 | 관심 학습과 일반 목록을 먼저 표시. 선택할 분야·학습 역량 제안은 가능하지만 선택을 강제하거나 부족 역량으로 표시하지 않음 |
| 4 | 신입 지원 또는 학생의 첫 취업 탐색이고, 유효한 비교에 보완 후보가 있음 | 공고 보완으로 진입해 이번 SNS·마케팅 지원 범위의 후보 기준으로 교육을 바로 표시. 지원 밖·근거 미준비가 있으면 별도 안내. 사용자는 좁히거나 해제 가능 |
| 5 | 완료된 유효 비교에서 보완 후보가 0개 | 관심 학습과 일반 목록 제공. 이번 공고·입력 범위에서 추가 보완 항목이 확인되지 않았다고만 안내 |
| 6 | 비교 결과 없음·유효성 확인 실패·지원 목적 미상 | 관심 학습과 일반 목록. 분석 실패는 실패 안내를 병행하며 보완 항목 0개라고 해석하지 않음 |

신입·이직 여부는 현재 지원 목적을 우선한다. 재학생·재직 상태가 겹쳐도 학생이라는 이유로 신입 추천을 강제하지 않는다. 목적·로그인 프로필을 알 수 없으면 추측하거나 입력을 강제하지 않는다. 비교 없는 사용자가 공고 보완을 고르면 비교 시작/복귀 안내와 일반 목록을 제공한다.

#### 비교 결과 안내 띠

- 공고 보완 목적이며 현재 버전의 완료된 비교가 유효하고 적용할 보완 후보가 있을 때만 비교 안내 띠를 표시한다. 이번 결과에 포함된 실제 적용 역량명으로 문구를 구성한다. ‘숏폼 발행·영상 툴·트렌드·실무 경험’ 같은 예시를 모든 방문자에게 고정 표시하지 않는다.
- 비교 없음·미완료·참조/버전 오류·보완 0개·관심 학습에서는 비교의 부족 역량을 안내하는 띠를 숨기고 각 상태 안내와 일반 탐색을 제공한다. 준비된 비교 자료를 사용할 때도 해당 자료로 비교를 마친 흐름에서만 표시하고 시연 자료임을 알린다.
- 현재 화면 PR은 미비교 방문자에게 나오던 고정 띠를 제거한 상태다. 위 조건에 따른 동적 표시 연결은 11/6 Spec·개발 대상이며 구현 완료가 아니다.

#### 공고 보완 후보·0건 판정

- 접근 가능한 현재 비교 참조·버전·목표 공고·요구별 역량 ID/판정/근거를 검증한다. 선택 목록은 선택 사항이며 이번 비교의 유효 후보에 속해야 한다. 중복 ID는 한 번만 세고, 알 수 없는 ID·권한 없는 결과를 이름 유사도로 보정하지 않는다.
- 후보는 비교 가능한 요구 중 ‘일부’·‘없음’이다. ‘없음’은 화면에서 ‘입력에서 찾지 못함’으로 안내한다. ‘맞음’·비교 제외·관심/태도 요구는 보완 후보에서 제외한다.
- 전체 비교 보완 수·이번 지원 범위 후보 수·검수된 교육 연결 수를 구분한다. ‘보완 항목 없음’ 안내는 비교 완료·현재 버전·비교 가능한 요구 1개 이상·모든 해당 판정 확인·전체 보완 0개인 경우에만, 첫 진입 목적과 별도로 판단한다.
- 0개일 때는 ‘이번 공고와 입력한 경험의 비교에서 추가 보완 항목을 확인하지 못했어요. 배우고 싶은 분야를 골라보세요’로 안내한다. 합격 가능·충분한 경력·모든 역량 보유를 뜻하지 않는다.
- 분석 실패·판정 누락·전부 비교 제외, 지원 범위 밖, 교육 근거 미준비를 보완 0개로 처리하지 않는다. 유효하지만 지원 밖인 항목은 ‘해당 항목의 교육 추천은 아직 준비 중이에요’와 일반 탐색을 제공한다. 잘못된 식별자·권한 오류와도 구분한다.
- 자동 적용은 ‘비교 결과 기준’이라고 표시하며 ‘내가 선택한 항목’으로 표시하지 않는다. 이후 직접 선택은 첫 진입 표와 8절에 따라 우선한다.

#### 관심 학습 선택

분야·검색만으로도 탐색할 수 있고 검수된 지원 역량을 복수 선택해 좁힐 수 있다. 초기 선택은 비워 두며 로그인·이력서·공고를 요구하지 않는다. 이미 공고에서 ‘맞음’인 역량도 더 배우기 위해 고를 수 있다. 지원 밖 분야는 일반 탐색을 제공하고 미검수 역량·추천 근거를 생성하지 않는다.

#### 추천·정렬

- 현재 목적의 적용 역량에 검수된 연결이 있으면 관련 역량순, 없으면 5절 기본 정렬을 적용한다. 관심 학습은 비교 없이 직접 선택한 역량으로 정렬 가능하다.
- 서로 다른 연결 역량 수 내림차순 → 5절의 모집 상태 순 → 유효 모집 마감 오름차순 → 과정 식별자 순으로 정렬한다. 날짜가 없으면 같은 상태의 날짜 있는 항목 뒤에 둔다. 같은 역량의 여러 근거는 한 번만 센다. 동률은 식별자 순이다. 적합도·합격률로 표현하지 않는다.
- 관련 없는 일반 과정도 뒤에서 탐색 가능하다. 검색·분야 조건이 추천보다 우선한다.
- 연결 과정 0개는 ‘현재 조건에 맞는 관련 교육이 없어요’, 매핑 미준비·조회 실패는 ‘관련 교육 정보를 확인하지 못했어요’로 구분하고 일반 탐색을 유지한다.


## 7. 상세·교육 근거·공식 이동

- F07: 모든 과정은 정확한 ID의 공통 상세 또는 해당 공식 상세로 이동한다. 내부 상세 자료가 없는 과정을 edu-1421 상세로 대체하지 않는다. 단계별 내부 상세 준비 범위는 Spec에 목록으로 남긴다.
- 상세 필드: 과정명·캠퍼스·상태·모집/교육 기간·시간·장소·방식·비용/예치금/반환·자격/제외 조건·선발/제출 자료·커리큘럼·프로젝트·출처·기준일. 미확인은 ‘공식 사이트 확인’으로 표시한다. 빈 값을 무료·제한 없음으로 추정하지 않는다.
- F06: 기존 P2 정책 상세와 공식 링크를 유지한다. 정책 지원 내용·기간·기관·나이/거주/취업/소득/학력·추가/제외 조건·방법·제출 자료를 확인한다. 개인별 자격 충족 여부를 대신 판단하지 않는다.
- 공고 보완은 공고 요구 문장 + 연결 역량 + 공식 교육 내용/위치, 관심 학습은 직접 고른 역량 + 교육 근거를 표시한다. 분야·과정명·태그만으로 연결을 만들지 않는다. SNS·마케팅 지원 목록과 연결은 사전 검수한 정적 자료를 쓴다.
- 외부 링크는 새 창 이동을 알린다. 모집 중/신청 가능 상태이고 유효한 신청 주소가 있을 때만 신청 CTA를 켠다. 예정·종료·미확인은 공식 정보 확인 링크만 제공한다. 상시 교육도 공식 모집 가능성이 별도로 확인되지 않으면 신청 CTA를 켜지 않는다.
- 직접 신청 주소가 없으면 공식 안내로 연결하며 신청 완료라고 집계하지 않는다. 비용·자격·일정은 공식 안내 우선임을 표시한다.

## 8. 로그인·북마크·복원

### 8.1 11/6 프론트 시연과 본선 뒤

11/6은 예시 계정으로 로그인하고 `illo-user`, `illo-saved` 브라우저 저장을 사용한다. 실제 인증·계정별 서버 저장·계정 격리·다른 기기 동기화는 본선 뒤다. 로그인 화면과 저장함에 시연용·현재 브라우저 저장임을 알린다. 실제 개인정보나 비밀번호 검증을 제공한다고 표현하지 않는다.

### 8.2 로그인 후 한 번 자동 저장

- 비로그인 저장 요청은 항목 종류·ID·공개 표시 정보와 내부 복귀 위치·탭·탐색 조건을 보존한 후 P06으로 이동한다. 취소하면 저장하지 않는다.
- 예시 로그인 성공 후 원래 항목으로 돌아와 저장을 한 번 추가한다. 이미 저장된 ID는 유지한다. 콜백·새로고침·재시도가 중복 추가나 저장 해제로 작동하면 안 된다.
- 요청은 시연 로그인 복귀에서만 소비하고 소비 후 제거한다. 유효하지 않거나 만료된 요청·삭제된 항목은 자동 저장하지 않고 안내한다. 만료 시간·저장소와 복원 형식은 Spec에 명시한다.
- P04 저장에서 가입을 경유해도 원래 저장으로 복귀한다. 직접 가입은 기존 이력서 등록 경로를 유지한다. 브라우저 뒤로 취소와 다른 저장 요청 시작 시 기존 요청 처리도 Spec에 정의한다.
- 마감된 항목은 상태를 안내하면서 저장 가능하다. 저장 실패는 성공으로 표시하지 않고 재시도한다. 같은 브라우저의 P04·P05 저장 상태·개수·해제가 일치해야 한다. 브라우저 저장 용량/차단 오류를 테스트한다.
- 복귀 대상은 내부 허용 화면과 항목 ID로 제한한다. 주소에 이력서 원문·토큰을 싣지 않는다.

### 8.3 탐색 상태

탭별 검색·분야/기관·상태 필터·정렬·페이지·스크롤, 학습 목적별 역량과 자동/직접/전체 해제, 비교 참조·버전, 저장 대상·진입 출처를 복원한다. 목록→상세→목록, 로그인 복귀, 탭 왕복에서 유지한다. 선택·필터 변경은 첫 페이지, 화면 크기 변경은 보던 첫 항목을 포함하는 페이지로 보정한다.

목적별 선택은 분리한다. 마지막 선택 해제는 일반 정렬이며 새로고침으로 다시 자동 선택하지 않는다. 새 P03 명시적 선택이 이전 선택보다 우선한다. 비교 버전 변경·권한/참조 오류 시 이전 공고 보완은 중단하고 안내·일반 탐색을 제공한다. 별도 관심 선택은 유지한다. 공개 링크 공유로 개인 비교나 저장 의도를 자동 실행하지 않는다.

## 9. 상태·기준일과 본선 뒤 운영

- 한국시간 기준. 날짜만 있으면 해당 일 끝까지 포함하되 공식 시각 확인으로 표현하지 않는다. 오늘 마감/D-1을 표시하고 음수 D-day는 마감으로 바꾼다.
- 교육은 전체 자료를 노출하되 기준 자료의 모집 기간과 서비스 날짜를 함께 사용한다. 공식 마감이 우선이고 상태/기간 충돌·필수 날짜 누락은 확인 필요다. 화면 재활성화·날짜 경계에서 신청 CTA를 재평가한다.
- 정책 신청기간 코드는 0057001 특정기간, 0057002 상시, 0057003 마감이다. 날짜 없음=상시 추정은 금지한다. 여러 신청 구간은 개별 판정하며 중간 공백은 신청 중으로 처리하지 않는다.
- 목록·상세에 실제 자료 기준일을 표시한다. main의 ad97c5f에서 마감 83건 오분류가 수정됐으며 재빌드 기준 신청 가능은 50건이다. 본 PRD는 실시간 재조사 결과를 뜻하지 않는다.
- **본선 뒤:** 매일 상태 확인·실패 기록·알림·운영 담당, 마지막 성공 확인 후 경과 >=48시간의 확인 필요 전환과 추천/신청 목록 제외, 복구를 운영한다. 11/6 시연에서는 자동 작업·48시간 만료로 자료를 숨기지 않고 기준일과 공식 재확인 안내로 대신한다.
- 상태 확인일과 교육 근거 검수일은 별도다. 내용 변경 시 매핑 재검수가 필요하다. 단일 수집 실패를 삭제로 해석하지 않는다.

## 10. 오류·접근성

로딩/정상 0건/조회 실패를 구분한다. 늦은 이전 응답은 최신 검색을 덮지 않는다. 추천 참조·매핑 실패 시 일반 탐색은 유지한다. 상세 실패 때 다른 과정으로 바꾸지 않는다. 정책 오류는 해당 항목 재시도/공식 링크를 제공한다. 저장 실패 시 직전 상태를 유지한다.

키보드 탭·선택 상태·포커스 복귀를 지원하고 입력/저장 버튼에 이름을 제공한다. 모바일 가로 넘침을 막고 주요 터치 영역은 44px 이상으로 한다. 검색·필터·상세·공식 이동·저장 완료를 구분하며 외부 이동을 실제 신청/취업 완료로 세지 않는다.
