- 사용자 요청으로 `Lsh`의 P03 개정과 로컬 P04 작업을 함께 `main`에 반영한다. P03-F13·P03-F14의 기존 내용과 팀 검토 대기 상태를 유지한다.
- P04 PRD를 v1.3으로 정리했다. 사용자 확정 범위, Goal 5개·Non-Goal 10개, 기능 19개·수용 기준 42개, 데이터·로그인·저장·복귀·오류 규칙과 담당자 간 합의 항목을 포함한다.

- 문서의 기능·목표·수용 기준 ID, 상대 링크, 표 구조와 차이를 확인한다. 화면·구현 코드 변경이 없는 문서 통합이므로 빌드·브라우저 기능 테스트는 대상이 아니다.
- 사용자 요청은 문서 병합에 대한 지시다. P03·P04의 팀원 리뷰, 미결 사항 합의, Spec과 실제 구현의 완료로 간주하지 않는다.

## 작업 순서 확인 원칙

2026년 11월 1일 사용자 요청에 따라, 이후 수정 요청은 관련 페이지 PRD의 개정안으로 먼저 정리한다. `CLAUDE.md`, `CONTRIBUTING.md`, PRD·Spec 가이드와 관련 명령 규칙을 확인한다. PRD 변경 요약을 제시하고 사용자 확인을 받은 뒤 반영하며, 팀원 1명 리뷰 → Spec → 코드·테스트 순서를 따른다. 요청이 이 순서를 건너뛰면 위반되는 단계와 근거를 설명하고 진행 전에 사용자에게 다시 확인한다. 사용자의 개정안 확인은 팀원 리뷰 완료로 간주하지 않는다.

## 2026년 11월 1일 나의 이력서 수정 버튼 PRD 작성

- 사용자 승인 와이어프레임을 [P03 PRD](prd/P03-compare.md)의 `P03-F14`로 추가했다. v1.2 초안·팀 검토 대기다.
- 경험 카드 안의 작은 수정 링크를 제거하고, 카드 밖에서 "AI로 비교하기" 바로 위에 "나의 이력서 수정"을 같은 너비·높이 54px로 배치한다. 간격은 8px이며 수정 버튼은 회색, AI 비교는 파란색이다.
- 기존 이력서 화면 이동, 데스크톱·모바일 배치, 빈 이력서 정책과의 관계, Given/When/Then 수용 기준을 정리했다.
- 영향 파일은 `docs/prd/P03-compare.md`와 이 수정 기록이다. 기존 P03-F13 개정안은 유지하며, 코드·Spec·P05 PRD는 수정하지 않았다.
- 문서의 기능 ID·수용 기준·이동 대상과 기존 PRD의 이력서 없음 정책을 대조했다. 구현·브라우저 검증은 팀 리뷰 후 구현 단계에서 수행한다.

## 2026년 11월 1일 트렌드 변경 원복과 PRD 전환

- 사용자 개정안 확인 후 [P03 PRD](prd/P03-compare.md)에 `P03-F13`을 추가했다. 버전은 v1.1 초안이며 팀 검토 대기다. 진입점별 동작, 결과 유지, 반복 열기·닫기, 데스크톱·모바일 수용 기준과 제외 범위를 기록했다.

- `sh design/build.sh` 재생성 성공. `git diff --exit-code -- design prototype` 통과로 코드와 생성물이 변경 전 기준과 동일함을 확인했다.

## 2026년 11월 1일 공고 비교 페이지의 트렌드 닫기 동작

### 요청

공고 비교 페이지의 자격요건 → Skillset → 트렌드 보기에서 연 창은 닫으면 원래 비교 페이지로 돌아온다. 다른 진입점의 기존 동작은 유지한다.

### 변경 내용

- 비교 페이지에서 공고 목록으로 이동하던 링크를 현재 페이지의 트렌드 팝업 열기로 변경했다.
- X 또는 하단의 공고 비교로 돌아가기 버튼을 누르면 팝업만 닫힌다. 기존 비교 결과는 유지된다.
- 데스크톱과 모바일 비교 페이지에 동일하게 적용했다.
- 공통 팝업의 하단 문구에 선택 인자를 추가했다. 기본값은 기존 공고 목록으로 돌아가기이며, 홈과 목록의 호출은 변경하지 않았다.

### 영향 파일

- `design/screens/01_base.py`: 팝업 하단 문구 선택.
- `design/screens/30_compare.py`: 비교 페이지 팝업 상태와 열기 버튼.
- `design/canvas/S3-compare.dc.html`, `design/canvas/m-S3-compare.dc.html`: 재생성된 캔버스.
- `prototype/S3-compare.html`, `prototype/m-S3-compare.html`: 재생성된 배포용 화면.

### 확인 결과

- `sh design/build.sh` 성공.
- `git diff --check` 통과.
- 임시 Chromium 브라우저에서 AI로 비교하기를 누른 후 아래 여섯 경로를 직접 실행해 검증했다.

| 화면 | 동작 | 확인 결과 |
|---|---|---|
| 데스크톱 비교 | 트렌드 열기 → X | 동일 URL, 팝업 닫힘, 비교 결과 유지 |
| 데스크톱 비교 | 트렌드 열기 → 공고 비교로 돌아가기 | 동일 URL, 팝업 닫힘, 비교 결과 유지 |
| 모바일 비교 | 트렌드 열기 → X | 동일 URL, 팝업 닫힘, 비교 결과 유지 |
| 모바일 비교 | 트렌드 열기 → 공고 비교로 돌아가기 | 동일 URL, 팝업 닫힘, 비교 결과 유지 |
| 데스크톱 목록 | 트렌드 → 공고 목록으로 돌아가기 | 목록 유지, 팝업 닫힘 |
| 모바일 목록 | 트렌드 → 공고 목록으로 돌아가기 | 목록 유지, 팝업 닫힘 |

수정 전후 diff를 재검토했다. 생성 결과의 변경은 비교 화면 네 파일에만 있으며 홈·목록 화면은 기존과 동일하다. 로컬 파일을 실제 브라우저에서 확인했으며 배포 서버에는 반영하지 않았다. 전체 서비스 QA나 모든 화면 크기의 시각 검증을 수행한 것은 아니다.
