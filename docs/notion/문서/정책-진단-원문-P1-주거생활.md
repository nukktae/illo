## 요약

- **쏠림과 미달이 동시에 생긴다.** SH 2026년 1차 청년매입임대는 81.9:1인데, 같은 공고 안에서 강동 희망50C 1,002:1과 금천 은슬림10 11:1이 공존하고 1순위 미달 주택형이 32개였다.
- **청년안심주택 보증금 사고.** 4개 사업장 297세대가 369.9억 원을 돌려받지 못했고, 4곳 모두 임대보증금 보증에 가입하지 않은 상태였다. 위험 노출은 8개소 1,231가구다.
- **예산이 남는데 못 받는다.** 임차보증금 이자지원 2024년 불용률 39.5%(미집행 393억 원), HUG 청년전용 보증부월세대출 실행률 2.0%.
- **서류 하나로 탈락한다.** 청년월세지원은 필수서류 누락 시 즉시 탈락이고 이의신청 기간에 추가 제출이 불가하다. 국토부 청년월세 부정수급의 79%는 행정 오류였다.
- **탈락·포기 사유를 아무도 집계하지 않는다.** HUG, LH, 서울시 모두 미실행·입주 포기 사유 데이터를 공개하거나 보유하지 않는다.
- **공급이 끊겼다.** 청년안심주택 신규 인허가는 최근 2년 0건이다.
