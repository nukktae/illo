# DDP 해커톤 · 일로 핵심 정리

기준: 2026.11.01 · [원문](https://app.notion.com/p/DDP-3f79b3c17c3b80aea549f79dcbb67838)

## 서비스

- **목표:** 채용공고 요구와 개인 경험을 비교하고, 다음 준비를 SeSAC 교육·프로젝트·지원 행동으로 연결.
- **MVP 직무:** 신입 SNS 콘텐츠 마케팅.
- **핵심 대상:** 동아리·학생회 SNS 운영 경험이 있지만, 공고에 맞는 경험인지 판단하지 못하는 취업준비생.
- **해결할 문제:** 지원 미루기, 불필요한 강의·자격증 비용 지출, 교육과정 선택의 어려움.

## 핵심 기능

1. 목표 공고와 내 경험 입력.
2. 요구 역량별 공고 문장·경험 문장 비교.
3. 보완할 항목을 사용자가 선택.
4. 교육·자격증/어학·프로젝트/대외활동·지원 준비로 연결.
5. 선택한 다음 행동을 내 경로에 저장.

- **메뉴:** 홈 · 직무 찾기 · 교육과정 · 마이페이지.
- **AI 역할:** 공고·경험에서 역량과 근거 문장 추출. 합격 예측·최종 결정은 제외.
- **결과 표시:** 맞음 · 일부 · 입력에서 찾지 못함. 출처·기준일·AI 사용 지점 표시.
- **시연 목표:** 한 사례로 입력 → 비교 → 다음 행동까지 2분.

## 차별화 방향

- **목표 공고의 요구 → 개인 경험의 근거 → 준비 순서 → SeSAC 수업**을 연결.
- 고용24 잡케어와 역량 분석·교육 추천 기능이 겹침. 기능 목록보다 연결된 실제 결과로 차이를 입증.
- SeSAC만 권하지 않고 프로젝트·인턴·바로 지원 등 다른 경로도 제공.
- 서울시 정책 연계 목표는 SeSAC 지원 전 과정 선택과 준비 지원.

## 현재 상태와 우선 작업

- 프론트엔드 프로토타입·Vercel 배포 완료. 백엔드 미구현, 개발 담당 범위 확정 필요.
- **개발 순서:** 페이지별 PRD 검토 → Spec 작성 → 핵심 비교 기능 구현 → 오류·예외 검증.
- **사용자 검증:** 5~6명 대상 테스트. 마케팅 지망생과 SeSAC 탈락·중도 포기 경험자 포함.
- **검증할 것:** 결과 이해 여부, 근거 신뢰도, 다음 행동 선택 가능 여부.
- **발표 전:** 담당자·발표자 확정, 실제 비교 결과 확보, 경쟁 서비스 대비 문구와 수치 출처 점검.
- 취업률 향상·추천 정확도 우위는 미검증. 실제 성과로 제시하지 않음.
