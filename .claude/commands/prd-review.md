description: PRD를 팀 체크리스트로 검토한다 (예: /prd-review P03)
argument-hint: P01~P06
---

`docs/prd/` 의 $ARGUMENTS PRD를 검토한다. 파일은 고치지 않고 의견만 낸다. 한국어로 답한다.

1. 읽기: `CLAUDE.md`, `docs/prd/00-root.md`, 해당 PRD, `docs/guides/01-prd.md` 체크리스트, 이 페이지와 닿는 다른 PRD.
2. 체크리스트 항목마다 통과, 문제, 해당 없음으로 표를 만든다. 문제는 줄 위치와 고칠 문장 제안까지.
3. 특히 볼 것: 합격 예측처럼 원칙을 어기는 말, 기능 ID 빠짐, 예외와 빈 상태 빠짐, 확인할 수 없는 수용 기준, 출처 없는 숫자, 다른 PRD와 부딪히는 이름이나 데이터.
4. 마지막에 가장 중요한 3가지를 우선순위로 정리한다.
